# Projects Hub — продуктовая спецификация 27 сентября 2026

Статус: **проектирование для реализации**, не отчёт о готовом приложении. Рекомендованное публичное имя — **Содей / Sodey**, пока без переименования репозитория, пакета и consumer `projects-hub`. Название требует отдельного утверждения и проверки прав.

## Решение

Единый голосовой координатор нескольких проектов и сообществ: **идея → обсуждение → решение → принятое обязательство → проверенный результат**. Большая кнопка записи, видимый контекст доступа, короткие карточки результата. Личный слой изолирован от группового.

Насыщенный MVP: PWA для участников и компьютера, компактный Android-клиент для длительной/офлайн-записи; один backend на DevCoveer. Идеи и документация версионируются в разрешённых GitHub-репозиториях; оперативные состояния, доступы и очереди принадлежат отдельной прикладной PostgreSQL. Общая Supabase authority остаётся только общей системой управления Live-ресурсом, а не базой содержимого продукта.

## Важнейший риск до подключения реальных данных

Условия и региональная доступность выбранного Live-провайдера должны соответствовать аудитории и типам данных. Нельзя автоматически считать существующий пул ключей допустимым для конфиденциальной многопользовательской работы или для пользователей в России. Это отдельный release gate, не предложение обходить ограничения и не запрет на разработку независимого ядра продукта. Подробности: [Live](06-live.md) и [источники](09-research.md).
