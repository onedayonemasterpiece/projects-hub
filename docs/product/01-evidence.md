[Общий индекс](README.md). Дата исследования: 2026-09-27. Канонический срез первоисточников: `onedayonemasterpiece/idea-hub@f9b7991c973282f111ef46742cd8cc1de4139469`.

## Метод и граница полноты

Изучены оригинальные текстовые расшифровки 18 релевантных голосовых: 7 формирующих текущий продукт и 11 более ранних. Индекс voice inbox просмотрен за 28 августа — 27 сентября; поиск проведён по разным написаниям проекта, коллективной работе и связанным продуктам. GitHub code search отставал от main, поэтому новые записи найдены через актуальное дерево и прямой поиск в синхронизированной копии. Это не утверждение, что все записи архива прослушаны или что семантически связанные записи невозможно пропустить.

Время в идентификаторах сохранено из исходных файлов; не пересчитывать его в часовой пояс читателя без исходного timezone. Аудио повторно не прослушивалось. Автоматические выжимки и старые советы модели не равнозначны словам владельца. Неопределённые фрагменты не домысливаются.

## Эволюция замысла

Сначала появился надёжный личный голосовой inbox. Затем — общие банки идей для групп, личный бизнес-помощник и клиент рабочих интеграций LADENO. Новые голосовые добавили то, чего нет в простом диктофоне: обратный диалог, согласование позиций разных людей и фиксацию совместного результата. Поэтому новое ядро — координация людей, а не ещё одна оболочка над транскрипцией.

LADENO остаётся архитектурной родословной; Record Idea Hub — работающим предшественником захвата. Projects Hub — самостоятельный продукт с собственными доступами и жизненным циклом групповой работы. Никто не получает доступ к личному idea-hub владельца только из-за участия в новом продукте.

## U02: прямое уточнение владельца, 27 сентября 2026

U02 — сообщение в текущем диалоге после первого анализа, не новая найденная голосовая. Владелец уточнил: PWA и Android — полноценные приложения с практически единым UI и дополнительными возможностями Android; свободный текстовый ввод не нужен; основа — Live-разговор, а не форма отправки/редактирования. Проекты выбираются также голосом и агентом по контексту. Вопросов может быть столько, сколько нужно для результата.

Длинная речь без сети должна сохраняться с VAD и целиком доходить до последующего диалога. Сброс/новый разговор не означает утрату записанного. Значимые исходные высказывания сохраняются отдельным Markdown с возможностью позднего поиска/возврата; длительность около 20 секунд предложена как ориентир, не запрет сохранять короткое важное. Словари переиспользуют подходы Record Idea Hub и Wonderful Lections и могут пополняться агентом по документам.

Эта ревизия отменяет противоречащие рекомендации первого анализа. Конкретные правила архивации, временного retention и checkpoint — инженерные предложения, не дословная формулировка владельца. Проверенные источники словарей перечислены в [документе 11](11-routing-and-vocabulary.md); новый [Live-контракт](live-contract.json) связан с U02.

## Актуальные разрешения конфликтов

| Напряжение | Решение ревизии 2 |
| --- | --- |
| Сложная координация и простой вход | Непрерывный Live-разговор, одна основная кнопка, контекстные выборы; без composer/формы отправки |
| Разные платформы | Два полноценных приложения с единым UX; Android расширяет возможности, не заменяет общий сценарий |
| Много проектов | Агент меняет фокус по голосу/смыслу, уточняет неоднозначность; сервер проверяет каждый целевой объект |
| Личное и общее | Личный многопроектный разговор и приватный исходник; группам только разрешённые фрагменты |
| Сохранность и полезность архива | Сначала durable source, затем оценка; важное при любой длительности, сомнительное не удаляется |
| Отсутствие сети | Полная запись/manifest/распознавание, затем полный текст Live-агенту и ответ о результатах |
| Новый разговор | Прежний источник сохраняется и ждёт продолжения, а не смешивается с новой беседой |
| Вопросы модели | Столько, сколько нужно для цели, без повторения уже известного и искусственного лимита |
| Общий ресурс | Существующие SDK и quota authority; запись не теряется при отсутствии AI |
| Словарь | Самостоятельное grounded-пополнение по документам/поправкам, версии и область доступа |
| Библиотека медиа | По V06 позднее; надёжный архив исходной речи, напротив, обязателен в MVP |

## Материализация

Этот пакет — owning product specification для Projects Hub. Исходные голоса и их исторические расшифровки остаются в IdeaHub без переписывания. Добавляется обратная ссылка из IdeaHub; закрытие registry/intake требует отдельной проверки полного маршрута и не подразумевается публикацией этих документов.
