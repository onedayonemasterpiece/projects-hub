# Projects Hub implementation rules

Owner vision and provenance live in docs/vision.md. This repository is the future replacement of Record Idea Hub, not permission to disable the working recorder/inbox.

Reuse live-interaction and the private deployment-installed ai-resource-control SDK. No raw Google key fallback, no second audio/VAD implementation, no browser service-role token. Scope is authorized on the server. Content changes require expected revision and durable command id; assistant tool arguments cannot grant repository access.

Current code is a tested resource integration boundary, not a complete Android/backend product. Production Live remains disabled pending shared transport guard, real quotas and canary acceptance. Read docs/resource-rollout.md before calling a provider. Never describe a mock-only test as microphone/provider acceptance.
